# ถ้าอ่านคนเดียว ให้ทดสอบการถอดเสียง ถ้ามีสองคนจะทดสอบการแยกคนพูดได้ด้วย
# CAST: ชาย+หญิง
# TERMS: ศัพท์ที่ต้องออกมาเป็นภาษาอังกฤษ

TERMS: code review, pull request, merge, branch, commit, refactor, function, variable, test, coverage, edge case, null, exception, log, performance, query, index, cache

ต้น: พี่ฝ้ายครับ ผมเปิด pull request ไว้เมื่อวานแล้ว รบกวนช่วย code review ให้หน่อยครับ
ฝ้าย: เห็นแล้วค่ะ เมื่อเช้าเพิ่งอ่านผ่านๆ ไป มีสองสามจุดที่อยากคุยด้วย
ต้น: ได้เลยครับ จุดไหนบ้าง
ฝ้าย: จุดแรกคือ function ที่ชื่อว่า process ตัวนี้ยาวเกินไปนะ มันทำอยู่สี่อย่างในตัวเดียว
ต้น: จริงครับ ผมก็รู้สึกเหมือนกัน เดี๋ยวผม refactor แยกออกเป็นสามตัวให้
ฝ้าย: อีกจุดคือตรงที่ query database แล้วไม่ได้เช็ค null เลย ถ้าไม่เจอข้อมูลมันจะโยน exception ออกมา
ต้น: อันนั้นผมลืมจริงๆ ครับ เดี๋ยวเพิ่ม test ให้ครอบคลุม edge case ตรงนั้นด้วย
ฝ้าย: แล้ว coverage ตอนนี้เท่าไหร่คะ
ต้น: ประมาณเจ็ดสิบสองเปอร์เซ็นต์ครับ ยังไม่ถึงเป้าที่เราตั้งไว้แปดสิบ
ฝ้าย: งั้นรอบนี้ขอให้ขึ้นไปให้ถึงก่อนค่อย merge นะคะ
ต้น: รับทราบครับ อีกเรื่องคือผมใส่ log เพิ่มตรง performance ที่ช้า อยากให้ดูด้วยว่าเยอะไปไหม
ฝ้าย: เดี๋ยวดูให้ค่ะ ถ้ามันเขียนทุก request ก็เยอะไป เอาเฉพาะที่เกินหนึ่งวินาทีพอ
ต้น: โอเคครับ เดี๋ยวผมแก้แล้ว commit เพิ่มใน branch เดิม แล้วบอกพี่อีกทีครับ
