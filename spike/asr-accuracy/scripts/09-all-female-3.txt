# จำลองประชุม 3 คน หญิงล้วน — เคสยากสำหรับการแยกคนพูด เพราะช่วงเสียงใกล้กัน
# CAST: หญิงล้วน
# TERMS: ศัพท์ที่ต้องออกมาเป็นภาษาอังกฤษ

TERMS: design, prototype, user flow, feedback, usability, accessibility, component, spacing, color, dark mode, handoff, ticket, sprint, release, mockup

ฝ้าย: วันนี้เรามารีวิว prototype ของหน้าชำระเงินกันนะคะ
มิ้น: มิ้นลองกดดูแล้วค่ะ รู้สึกว่า user flow มันยาวไปนิดนึง มีถึงห้าขั้น
แนน: แนนก็คิดแบบนั้นค่ะ จาก feedback ของผู้ใช้รอบที่แล้ว หลายคนหลุดตรงขั้นที่สาม
ฝ้าย: ถ้าเรารวมขั้นที่สามกับสี่เข้าด้วยกันจะได้ไหมคะ
มิ้น: ได้ค่ะ แต่หน้าจอจะแน่นขึ้น ต้องคิดเรื่อง spacing ใหม่ทั้งหมด
แนน: แล้วเรื่อง accessibility ด้วยนะคะ ตัวอักษรตอนนี้เล็กเกินเกณฑ์อยู่แล้ว
ฝ้าย: จริงค่ะ แล้ว color ที่ใช้บนปุ่มหลัก contrast ยังไม่ผ่านด้วย
มิ้น: มิ้นจะแก้ทั้งสองอย่างในรอบนี้ค่ะ แล้วทำ dark mode ให้ครบทุก component ด้วย
แนน: ถ้าแก้เยอะขนาดนี้ handoff ให้ทีมพัฒนาทันสิ้น sprint ไหมคะ
ฝ้าย: ฝ้ายว่าน่าจะไม่ทันค่ะ ขอแยกเป็นสอง ticket ดีกว่า
มิ้น: เห็นด้วยค่ะ รอบนี้เอาแค่ usability กับ accessibility ก่อน
แนน: ส่วน dark mode ค่อยไป release รอบหน้า
ฝ้าย: สรุปตามนี้นะคะ เดี๋ยวฝ้ายอัปเดต mockup แล้วส่งในกลุ่มค่ะ
