# จำลองประชุม 3 คน ชายล้วน — เคสยากสำหรับการแยกคนพูด เพราะช่วงเสียงใกล้กัน
# CAST: ชายล้วน
# TERMS: ศัพท์ที่ต้องออกมาเป็นภาษาอังกฤษ

TERMS: deploy, staging, production, branch, merge conflict, rebase, pull request, unit test, coverage, timeout, retry, queue, worker, log, index, query

ต้น: เมื่อวานผมลอง merge branch ของบอยเข้ามา แล้วเจอ merge conflict เยอะมากครับ
บอย: ผมก็เจอเหมือนกันครับพี่ เพราะเราสองคนแก้ไฟล์เดียวกันคนละที่
เอก: ผมว่าเราควร rebase ให้บ่อยกว่านี้นะ ทิ้งไว้ห้าวันแบบนี้มันเละแน่นอน
ต้น: จริงครับ ต่อไปขอเป็นทุกเช้าเลยดีกว่า
บอย: แล้วเรื่อง queue ที่ผมทำอยู่ ตอนนี้ worker มันค้างบ่อยมากครับ
เอก: ค้างเพราะอะไรครับ ดู log แล้วเจออะไรบ้าง
บอย: เจอ timeout ตอนดึงข้อมูลครับ แล้วมันก็ retry วนไปเรื่อยๆ ไม่ยอมหยุด
ต้น: ต้องใส่จำนวนครั้งสูงสุดของ retry ด้วยนะครับ ไม่งั้นมันวนจนตาย
เอก: แล้ว query ที่มันช้า ใส่ index ให้แล้วหรือยัง
บอย: ยังครับ เดี๋ยวผมทำวันนี้ แล้วจะเขียน unit test เพิ่มด้วย
ต้น: coverage ตอนนี้เท่าไหร่แล้วครับ
บอย: หกสิบแปดครับ ยังไม่ถึงเป้า
เอก: งั้นรอบนี้ยังไม่ขึ้น production นะ ขึ้นแค่ staging ก่อน
ต้น: ตกลงตามนั้นครับ ผมจะเปิด pull request รวมให้ตอนเย็น
