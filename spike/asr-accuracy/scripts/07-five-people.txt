# จำลองประชุม 5 คน — วางแผนปล่อยของรอบใหญ่
# CAST: ชาย+หญิง
# TERMS: ศัพท์ที่ต้องออกมาเป็นภาษาอังกฤษ

TERMS: release, deploy, staging, production, feature flag, rollout, rollback, regression, test, bug, hotfix, downtime, backup, migration, monitoring, alert, on-call, checklist

ต้น: ประชุมวันนี้เรื่องปล่อยของรอบใหญ่สัปดาห์หน้านะครับ ทุกคนอยู่ครบแล้ว
ฝ้าย: ฝั่งพัฒนาพร้อมแล้วค่ะ เหลือ bug ตัวเดียวที่ยังไม่ปิด แต่ไม่ใช่ตัวบล็อก
บอย: ฝั่ง test ผมรัน regression ครบแล้วครับ ผ่านหมด ยกเว้นเคสเดียวที่เกี่ยวกับเวลาโซนต่างประเทศ
มิ้น: monitoring ผมตั้ง alert เพิ่มไว้แล้วครับ ถ้า error rate เกินสองเปอร์เซ็นต์จะเด้งทันที
ปอ: ฝั่งดูแลระบบ ปอเตรียม backup ของ database ไว้ก่อน deploy แล้วค่ะ แล้วก็ซ้อม rollback มาแล้วหนึ่งรอบ
ต้น: ดีมากครับ แล้วเรื่อง downtime เราจะใช้เวลาเท่าไหร่
ปอ: ถ้า migration ไม่มีปัญหา ประมาณสิบนาทีค่ะ แต่เผื่อไว้สามสิบดีกว่า
ฝ้าย: ฝ้ายเสนอว่าให้ขึ้นหลัง feature flag ทั้งหมดนะคะ แล้วค่อย rollout ทีละสิบเปอร์เซ็นต์
บอย: เห็นด้วยครับ แบบนั้นถ้าเจอปัญหาก็ปิด flag ได้เลย ไม่ต้อง rollback ทั้งก้อน
มิ้น: แล้วใครเป็น on-call คืนนั้นครับ
ต้น: ผมกับปอครับ ผมดูฝั่งแอป ปอดูฝั่งระบบ
ปอ: รับทราบค่ะ เดี๋ยวปอทำ checklist ก่อน deploy ส่งให้ทุกคนพรุ่งนี้
ต้น: สรุปนะครับ ขึ้น staging วันจันทร์ ทดสอบวันอังคาร ขึ้น production คืนวันพุธ
ฝ้าย: ถ้ามีอะไรผิดพลาดเรามี hotfix ได้ภายในกี่ชั่วโมงคะ
ต้น: ตั้งเป้าไว้สองชั่วโมงครับ ถ้าเกินนั้นให้ปิด flag แล้วค่อยแก้ตอนเช้า
ต้น: ขอบคุณทุกคนครับ เจอกันวันจันทร์
