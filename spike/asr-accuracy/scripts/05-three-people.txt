# จำลองประชุม 3 คน — standup ตอนเช้า
# TERMS: ศัพท์ที่ต้องออกมาเป็นภาษาอังกฤษ

TERMS: standup, sprint, ticket, blocker, deploy, staging, production, API, endpoint, schema, migration, test, bug, release, dependency

ต้น: สวัสดีครับทุกคน มา standup กันนะครับ เริ่มจากผมก่อน
ต้น: เมื่อวานผมทำ endpoint ใหม่เสร็จแล้ว ขึ้น staging ไปแล้วด้วย วันนี้จะเขียน test เพิ่ม
ต้น: ไม่มี blocker ครับ ฝ้ายต่อเลย
ฝ้าย: เมื่อวานฝ้ายแก้ bug ที่หน้ารายการสินค้าค่ะ ตัวที่โหลดซ้ำสองรอบ
ฝ้าย: วันนี้จะทำ migration ของ schema ใหม่ แต่ติดตรงที่ต้องรอ ticket ของบอยก่อน
ฝ้าย: อันนี้ถือเป็น blocker ค่ะ
บอย: ของผมเสร็จบ่ายนี้แน่นอนครับพี่ฝ้าย เมื่อวานติดเรื่อง dependency ที่เวอร์ชันไม่ตรงกัน
บอย: วันนี้แก้เสร็จแล้ว เหลือแค่รัน test ให้ผ่านครบ
ต้น: ดีครับ งั้นฝ้ายเริ่มได้ตอนเย็น
ฝ้าย: ค่ะ แล้ว release รอบนี้เราจะขึ้น production วันไหนคะ
ต้น: ตามแผนคือวันพฤหัส แต่ถ้า migration ยังไม่นิ่งผมว่าเลื่อนเป็นศุกร์ดีกว่า
บอย: ผมเห็นด้วยครับ ขึ้นวันพฤหัสแล้วศุกร์ต้องมาแก้กันมันเหนื่อย
ต้น: งั้นเอาเป็นศุกร์นะครับ ผมจะแจ้งในกลุ่มให้ จบ standup ครับ
